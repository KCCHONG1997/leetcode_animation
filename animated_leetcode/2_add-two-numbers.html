Add Two Numbers

Two non-empty linked lists represent non-negative integers with their digits stored in reverse order. Add the numbers and return their sum as another reversed linked list. Each node contains one digit.

Linked ListMathRecursion
Input   l1 = [2, 4, 3]
        l2 = [5, 6, 4]
Output  [7, 0, 8]
Why     342 + 465 = 807

Walk through the solution

Enter two reversed digit lists and follow each node addition and carry.
Test input1 to 9 digits each
solution.py
def addTwoNumbers(l1, l2):    dummy = ListNode()    tail = dummy    carry = 0    while l1 or l2 or carry:        x = l1.val if l1 else 0        y = l2.val if l2 else 0        total = x + y + carry        carry = total // 10        tail.next = ListNode(total % 10)        tail = tail.next        l1 = l1.next if l1 else None        l2 = l2.next if l2 else None    return dummy.next
